Rules that apply to every line below: never write "pixel art" in a prompt; flat **magenta**
background with `remove_bg`; record prompt, style, seed and date in `art/prompts/`; run the
editor pass after adding PNGs; snap to `art/src/palette.png`; every sprite gets a one-texel
dark outline (the tools do this); Aseprite is at
`C:\Program Files (x86)\Steam\steamapps\common\Aseprite\Aseprite.exe` for headless builds.

Going through Codex instead, three of those rules change: there is no `remove_bg`, so
`art/tools/keyout.py` keys the magenta out; there is no seed, so the **prompt is the record**
and goes into `art/prompts/` in full; and every prompt ends with the same tail, of which
`flat solid colours` and `no shadow` are the two clauses doing real work.

## Gotchas paid for today (also in CLAUDE.md)

- `CPUParticles2D` never draws in this project; use `GPUParticles2D`. A particle effect is
  unfinished until a capture shows it.
- The Bash tool collapses backslashes in perl one-liners; Windows paths and `\\` continuations
  come out mangled. Use the Edit/Write tools for anything with a backslash.
- A perf stage must be placed around **him**, not the window; the stage report
  (`user://perf_<mode>.txt`) is the guard.
- The capture tool shares `settings.cfg` with the player; anything it forces it must restore
  (it does now).
- `python3` on the Git Bash PATH is the Store stub; Pillow is in WSL.
